# Combat Core

Status: DRAFT

Purpose:
Согласованная основа Combat; полного дизайна боя пока нет.

Основание: [CANON UPDATE 001](../updates/GENOME_CANON_UPDATE_001.md), §2. Он имеет приоритет над прежним NOT_STARTED и запретом документировать Combat только в пределах COMBAT-001–COMBAT-004. Это не утверждение всего MVP scope и не разрешение реализации.

## Утверждённые решения основы

Status: APPROVED

Область одобрения — только COMBAT-001–COMBAT-004 ниже, вместе с явно указанными границами. Полный состав характеристик, формулы, способности, баланс и остальные правила не утверждены. Частичное согласование функций по Update 002 и качественных ограничений по Update 003 описано отдельно ниже.

### COMBAT-001 — Размер команды

Каждая сторона использует команду из трёх существ: 3v3.

### COMBAT-002 — Асинхронный автоматический бой

Игрок готовит состав до боя. Во время боя ручных действий игрока нет. Соперникам не требуется одновременно находиться онлайн.

Точная модель защитного состава, доступной информации о противнике, подбора соперников и наград остаётся OPEN.

### COMBAT-003 — Расстановка

Три позиции: FRONT, BACK_LEFT, BACK_RIGHT.

FRONT — стандартная цель обычных одиночных атак. Способности и статусы могут явно изменять это правило. FRONT — позиция, а не обязательный класс Tank.

После выбытия FRONT один из задних существ занимает переднюю позицию. Правило выбора, момент перемещения и порядок взаимодействия со статусами пока OPEN; Codex не выбирает их сам.

### COMBAT-004 — Раундовая модель

Бой рассчитывается дискретными раундами. При одинаковых начальных данных, версии правил и RNG seed результат воспроизводим. Frontend отображает результат расчёта, а скорость анимации не меняет исход.

Набор случайных событий, порядок фаз раунда, инициатива, дополнительные действия, лимит раундов и разрешение ничьих остаются OPEN. Воспроизводимость не означает утверждение критов, промахов или иных случайных боевых механик.

[Combat Stats](COMBAT_STATS.md) фиксирует COMBAT-008 — производительность организма и распределение возможностей как производные от генетики; COMBAT-009 — различие тканей, защиты и двигательной системы без автоматического штрафа урону от максимального или текущего здоровья; COMBAT-010 — разные специализации нервной системы без обязательной слабости всех быстрых существ. ## Уточнения CANON UPDATE 004
